# Laravel AuthKit

Laravel AuthKit is a package that helps you add authentication and account security features to your Laravel application.

It supports both Web and API applications. Authentication in both modes uses Laravel sessions and cookies, managed by Laravel Sanctum. The API mode does not use Bearer Tokens or Personal Access Tokens.


### Features

- Web Authentication
- API Authentication
- Google Login
- Password Reset
- Email Verification
- Two-Factor Authentication (2FA)
- Recovery Codes
- Profile Management
- Password Management
- Session Management
- Security Activities
- Security Notifications


### Installation

You can install Laravel AuthKit using Composer:

```bash
composer require aliqsm/laravel-authkit
```

After installation, follow the documentation to configure and use the package.

### Documentation

The documentation explains how to install, configure, and use Laravel AuthKit.

- PHP 8.2 or higher
- Laravel 12 or 13
