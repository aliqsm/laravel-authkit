نصب و راه‌اندازی

پیش‌نیازها

پیش از نصب، مطمئن شوید محیط توسعه شما شرایط زیر را دارد:

  • PHP 8.2 یا بالاتر
  • Laravel 12 یا 13
  • Composer

۱. نصب پکیج

برای نصب AuthKit، دستور زیر را در ترمینال و در مسیر پروژه Laravel خود اجرا کنید: 

composer require aliqsm/laravel-authkit

پس از نصب، سرویس‌پرووایدر پکیج به‌صورت خودکار توسط Laravel شناسایی می‌شود.

۲. انتشار فایل تنظیمات

برای انتشار فایل تنظیمات AuthKit در پروژه خود، دستور زیر را اجرا کنید: 

php artisan vendor:publish --tag=authkit-config

فایل تنظیمات در مسیر config/authkit.php ایجاد می‌شود.

۳. انتخاب حالت اجرا

در فایل config/authkit.php، مقدار app_mode را بر اساس نوع رابط کاربری پروژه تنظیم کنید: 

'app_mode' => 'web',
  • web: برای استفاده از صفحات آماده Blade و احراز هویت در محیط وب.
  • api: برای اتصال رابط کاربری مستقل مانند React یا Vue به Backend از طریق API.

با انتخاب حالت مناسب، فقط Routeهای موردنیاز همان حالت در پروژه شما فعال می‌شوند.

۴. اتصال مدل User

برای استفاده از قابلیت‌های AuthKit، کافی است Trait پکیج را به مدل User پروژه خود اضافه کنید: 

use Aliqsm\LaravelAuthkit\Traits\HasAuthKit;

class User extends Authenticatable
{
    use HasAuthKit;
}

این Trait متدها و ویژگی‌های موردنیاز برای عملکرد صحیح AuthKit را به مدل کاربر پروژه اضافه می‌کند.

۵. انتشار فایل‌های Build

از آنجا که AuthKit دارای صفحات آماده با رابط کاربری اختصاصی است، برای نمایش صحیح استایل‌ها و عملکرد بخش‌های تعاملی این صفحات در حالت web، باید فایل‌های Build پکیج را در پروژه خود منتشر کنید: 

php artisan vendor:publish --tag=authkit-build

توجه داشته باشید که این فایل‌ها نسخه نهایی و کامپایل‌شده CSS و JavaScript هستند و با فایل‌های خام و قابل ویرایش پکیج تفاوت دارند. در حالت api نیازی به اجرای این دستور نیست.

۶. اجرای Migrationها

AuthKit برای ذخیره اعلان‌های کاربران از جدول notifications لاراول استفاده می‌کند. اگر جدول notifications از قبل در پروژه شما وجود دارد، کافی است دستور زیر را اجرا کنید: 

php artisan migrate

در غیر این صورت: 

php artisan make:notifications-table
php artisan migrate

۷. تنظیم و اجرای صف (Queue)

AuthKit برای ارسال ایمیل‌ها و اعلان‌های امنیتی از سیستم صف (Queue) لاراول استفاده می‌کند. برای پردازش این عملیات، باید اتصال صف را در فایل .env تنظیم کرده و یک Queue Worker فعال داشته باشید.

برای مثال، می‌توانید از اتصال پایگاه داده استفاده کنید: 

QUEUE_CONNECTION=database

در صورت استفاده از اتصال Database، ابتدا جدول موردنیاز صف را ایجاد کنید: 

php artisan make:queue-table
php artisan migrate

سپس برای پردازش کارهای قرارگرفته در صف، دستور زیر را در یک ترمینال فعال اجرا کنید: 

php artisan queue:work

در محیط Production نیز باید Queue Worker به‌صورت دائمی و با استفاده از ابزاری مانند Supervisor اجرا و مدیریت شود.
