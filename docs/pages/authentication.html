احراز هویت

ورود با حساب Google

AuthKit قابلیت ورود و ثبت‌نام با حساب Google را فراهم می‌کند و در پشت صحنه برای پیاده‌سازی این قابلیت از پکیج Laravel Socialite استفاده می‌کند. Socialite فرایند احراز هویت از طریق سرویس‌های خارجی را ساده می‌کند.

راه‌اندازی

ابتدا وارد Google Cloud Console شوید و یک پروژه ایجاد کنید. سپس از بخش OAuth، اطلاعات موردنیاز شامل Client ID و Client Secret را دریافت کرده و آدرس Callback پروژه خود را ثبت کنید.

سپس تنظیمات زیر را در فایل config/services.php قرار دهید: 

'google' => [
    'client_id' => env('GOOGLE_CLIENT_ID'),
    'client_secret' => env('GOOGLE_CLIENT_SECRET'),
    'redirect' => env('GOOGLE_REDIRECT_URI'),
],

مقادیر دریافت‌شده را در فایل .env وارد کنید: 

GOOGLE_CLIENT_ID=
GOOGLE_CLIENT_SECRET=
GOOGLE_REDIRECT_URI=https://example.com/oauth/google/callback

آدرس GOOGLE_REDIRECT_URI باید با آدرس Callback ثبت‌شده در Google Cloud Console یکسان باشد.

مسیرهای احراز هویت

AuthKit از مسیرهای زیر برای ورود، ثبت‌نام و احراز هویت کاربران در حالت Web استفاده می‌کند. این مسیرها به‌صورت خودکار و بر اساس مقدار app_mode در فایل پیکربندی ثبت می‌شوند.

ورود و ثبت‌نام
Method Url Route Name
GET /login login.form
POST /login login
GET /register register.form
POST /register register
GET /oauth/google/redirect oauth.google.redirect
GET /oauth/google/callback oauth.google.callback
POST /logout logout
بازیابی رمز عبور
Method Url Route Name
GET /forgot-password password.request
POST /forgot-password password.email
GET /reset-password/{token} password.reset
POST /reset-password password.update
احراز هویت دومرحله‌ای
Method Url Route Name
GET /2fa/challenge two-factor.challenge
POST /2fa/challenge two-factor.verify

ثبت‌نام، ورود با Google، بازیابی رمز عبور و احراز هویت دومرحله‌ای به فعال بودن قابلیت مربوطه در تنظیمات AuthKit وابسته هستند.

فعال‌سازی و مدیریت قابلیت‌ها

از طریق بخش features در فایل config/authkit.php می‌توانید قابلیت‌های مختلف AuthKit را متناسب با نیاز پروژه فعال یا غیرفعال کنید. مقدار true قابلیت را فعال و مقدار false آن را غیرفعال می‌کند. 

'features' => [
    'registration' => true,
    'google_login' => true,
    'two_factor_authentication' => true,
    'update_profile_information' => true,
    'change_password' => true,
    'security_activities' => true,
    'password_reset' => true,
],
معرفی قابلیت‌ها
  • registration — فعال‌سازی ثبت‌نام کاربران با استفاده از فرم ثبت‌نام.
  • google_login — فعال‌سازی ورود و ثبت‌نام کاربران از طریق حساب Google.
  • two_factor_authentication — فعال‌سازی احراز هویت دومرحله‌ای.
  • update_profile_information — فعال‌سازی امکان مشاهده و ویرایش اطلاعات پروفایل کاربر.
  • change_password — فعال‌سازی امکان تغییر رمز عبور حساب کاربری.
  • security_activities — فعال‌سازی ثبت و مشاهده فعالیت‌های امنیتی حساب کاربری.
  • password_reset — فعال‌سازی فرایند بازیابی رمز عبور از طریق لینک ارسال‌شده به ایمیل.
هشدار درباره غیرفعال‌سازی احراز هویت دومرحله‌ای

اگر کاربری قبلاً احراز هویت دومرحله‌ای را برای حساب خود فعال کرده باشد، با غیرفعال کردن two_factor_authentication، مسیرهای مربوط به تأیید دومرحله‌ای ثبت نمی‌شوند. در نتیجه، کاربرانی که احراز هویت دومرحله‌ای آن‌ها فعال است ممکن است دیگر نتوانند وارد حساب خود شوند. بنابراین، پیش از غیرفعال کردن این قابلیت، وضعیت احراز هویت دومرحله‌ای کاربران را بررسی و آن را برای حساب‌های فعال غیرفعال کنید.
