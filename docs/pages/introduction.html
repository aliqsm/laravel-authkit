Laravel AuthKit

معرفی

Laravel AuthKit مجموعه‌ای از ابزارها و قابلیت‌های آماده برای مدیریت احراز هویت و حساب‌های کاربری در Laravel است. این پکیج بخش‌های مختلف احراز هویت را در یک ساختار منسجم گردآوری کرده است تا بتوانید به‌سادگی امکاناتی مانند ثبت‌نام، ورود، بازیابی رمز عبور و تأیید دومرحله‌ای را به پروژه خود اضافه کنید.

تمام منطق مربوط به احراز هویت، کنترلرها، اعتبارسنجی درخواست‌ها و مدیریت پاسخ‌ها درون پکیج پیاده‌سازی شده‌اند. بنابراین نیازی نیست این بخش‌ها را در هر پروژه از ابتدا بنویسید یا فایل‌های داخلی پکیج را به پروژه خود منتقل کنید.

حالت‌های اجرا

AuthKit از دو حالت Web و API پشتیبانی می‌کند و می‌توانید متناسب با ساختار پروژه خود یکی از آن‌ها را انتخاب کنید. در هر دو حالت، احراز هویت با Laravel Sanctum و بر پایه Session و Cookie انجام می‌شود؛ تفاوت اصلی در نحوه ارائه رابط کاربری و پاسخ به درخواست‌ها است.

Web

اگر رابط کاربری پروژه شما با Laravel و Blade توسعه داده شده است، در حالت Web می‌توانید از صفحات آماده AuthKit برای احراز هویت و مدیریت حساب کاربری استفاده کنید.

API

اگر پروژه شما با فناوری‌هایی مانند React یا Vue توسعه داده شده است، AuthKit صفحات آماده ارائه نمی‌دهد و Endpointهای موردنیاز را در اختیار برنامه‌نویس قرار می‌دهد. درخواست‌ها به این Endpointها ارسال می‌شوند و پاسخ‌ها در قالب JSON بازگردانده می‌شوند.

توجه: احراز هویت در حالت API نیز بر پایه Session و Cookie انجام می‌شود و از توکن‌های احراز هویت پشتیبانی نمی‌کند.

قابلیت‌ها

  • ثبت‌نام، ورود
  • ورود و ثبت‌نام با حساب Google
  • تأیید آدرس ایمیل

  • احراز هویت دومرحله‌ای
  • مدیریت نشست‌های فعال
  • ثبت فعالیت‌های امنیتی
  • ارسال ایمیل رویدادهای امنیتی
